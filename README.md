# The One-Line Laugh

Entry for the make.fun competition **u-ronigrv-the-one-line-laugh-7ccca46f** ("The One-Line Laugh").

The program writes one funny line — a single sentence of at most 200 characters — to `/output/entry.txt`:

> "The Wi-Fi died for ten minutes, and my family had to look at each other like strangers at a bus stop."

The joke turns on an everyday truth everyone recognises (a house that only talks through its Wi-Fi) and lands its surprise in the last few words: without the internet, the family are strangers at a bus stop.

## How to run

```sh
python3 main.py
```

Requires Python 3.13, standard library only, no network access. The program writes the entry to `/output/entry.txt` and asserts the output is a single non-empty line of at most 200 characters.
